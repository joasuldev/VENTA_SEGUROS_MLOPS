## Diccionario de Seguro Antirobos

| Variable | Descripción |
|---|---|
| Mto_TC | Monto de oferta de TC |
| MARCA | Tipo de operador de la TC |
| Nombre_territorio | Nombre del territorio que pertenece el cliente |
| FLAG_LIMA_PROVINCIA | Flag Lima o Provincia |
| REGION | Región geográfica de residencia del cliente |
| SUELDO_ESTIMADO | Monto de sueldo |
| EDAD | Edad del cliente |
| SEXO | Sexo del cliente |
| ANTIGUEDAD_MES | Nro de meses de antigüedad del cliente |
| SEGMENTO | Segmento que pertenece el cliente |
| FLAG_SS | Venta o del seguro contra robos |
